# Compteur de clics

Petite page web avec un bouton dont chaque clic est enregistré dans une base SQLite locale.

## Lancer le projet

Depuis ce dossier :

```bash
python3 server.py
```

Ouvrir ensuite <http://127.0.0.1:8000> dans un navigateur.

Le compteur est conservé dans le fichier `clicks.db`, créé automatiquement au premier lancement.
